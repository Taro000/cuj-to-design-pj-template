# cuj-to-design-pj-template

CUJ から品質要件・設計までを Claude Code のスキルで進めるプロジェクトのテンプレート。

## 使い方

1. **Use this template** でリポジトリを作る。
2. clone して `sh scripts/init-from-template.sh` を実行する（要 `gh auth login`）。
3. できた PR を **Create a merge commit** でマージする。

運用ルールは `CLAUDE.md` と `.claude/rules/` を参照。
